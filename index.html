Make it a shared space

A free Supabase project gives Openroom shared rooms, live chat, and file uploads. No card needed on the free plan.

  1. Create a free Supabase project and wait for it to finish provisioning.
  2. In SQL Editor, run the script in setup.sql from this folder.
  3. Enable Anonymous Sign-Ins in Authentication settings.
  4. Copy the Project URL and publishable key from Project Settings → API.

This form connects only this browser. To connect the published site for everyone, set SHARED_SITE_CONFIG in index.html. Only use a public publishable key; never use a secret or service-role key. Posting is public to anyone with your site link.
